# BookmyBooth

เว็บจองล็อกขายของในตลาดนัด งานแฟร์ และงานมหาวิทยาลัย (เฉพาะหน้าบ้าน ข้อมูลเก็บใน localStorage ของเบราว์เซอร์)

- **ผู้ขาย** ดูผังงาน เลือกได้หลายล็อก จองทั้งงานและจ่ายครั้งเดียว
- **ผู้จัดงาน** วาดผัง ตั้งโซนและราคา อนุมัติการจอง (ต้องรอผู้ดูแลระบบอนุมัติบัญชี)
- **ผู้ดูแลระบบ** อนุมัติผู้จัดงาน และจัดการผู้ใช้

หนึ่งบัญชีมีบทบาทเดียว และเปิดได้เฉพาะหน้าของบทบาทนั้น

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิดที่ http://localhost:5173
npm run build    # ตรวจ TypeScript แล้ว build ลง dist/
npm run lint
```

## โครงสร้าง

| โฟลเดอร์ | เก็บอะไร |
|---|---|
| `src/pages` | หน้าเว็บ แยก `user` (ผู้ขาย) `organizer` และ `admin` |
| `src/components` | คอมโพเนนต์ แยกตามส่วน popup ทั้งหมดอยู่ใน `popup` ส่วน `ui` เป็นคอมโพเนนต์จาก shadcn/ui |
| `src/data` | ข้อมูลตั้งต้นและค่าตั้งค่า (`settings.ts`) |
| `src/services` | สร้างข้อมูลตั้งต้น คำนวณข้อมูลที่ได้จาก state และเรื่องบัญชี |
| `src/store` | state ของแอป บัญชีที่เข้าสู่ระบบ |
| `src/utils` | ฟังก์ชันช่วย เช่น ผังล็อก ราคา วันที่ |

ยังไม่มีระบบส่งอีเมล รหัสยืนยัน (OTP) จึงแสดงบนหน้าจอแทน ปิดได้ที่ `SHOW_OTP_ON_SCREEN` ใน `src/data/settings.ts` เมื่อมีหลังบ้านแล้ว
